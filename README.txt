熙叆角色资源站
==============

向日葵精灵「熙叆」的角色资源网站：四季时光碎片图库、三卷「会动的碎片」影像、
主题音乐与完整角色设定。与视觉小说《魔法时间的童话 ～熙叆的时光物语～》同属一套世界观。

【怎么打开】
1. 用 Chrome / Edge 浏览器双击 index.html 即可。
2. 本站需要与「熙叆」和「熙叆物语」两个文件夹放在一起（保持现在的目录结构）：
     D:\24436\Documents\
     ├─ 熙叆\          原始素材（73 张原图、3 段原片、wav 原声）
     ├─ 熙叆物语\       视觉小说游戏（图片 / 视频 / 音乐为网页版素材）
     └─ 熙叆角色资源站\ 本站（index.html 入口）

【页面导航】
- index.html    主页：角色资料卡、统计、四季精选、各功能区入口
- gallery.html  时光图库：73 枚碎片按「全部 / 序幕 / 夏 / 秋 / 冬 / 春」筛选，
                点击放大（灯箱，支持 ← → 键），「原图 ⬇」可查看/保存原始文件
- media.html    影音资源：三卷「会动的碎片」在线播放 + 原片下载，
                主题音乐《魔法时间的童话》循环播放 + wav 原声下载
- about.html    角色设定：熙叆与聆淅的完整设定、向日葵国度的世界观

【素材与生成】
- 缩略图（thumbs/ 480px 与 preview/ 1600px，WebP）由 tools/generate.js 自动生成，
  数据清单在 data/photos.json 与 js/photos.js（勿手改）。
- 新增照片后，更新「熙叆物语/images/manifest.json」，再运行：
     cd tools && npm install && node generate.js
  即可重新生成全部缩略图与图库数据。

【想发布到网上？】
本站是纯静态站，可直接上传任意静态托管（GitHub Pages / Cloudflare Pages 等）。
注意：原图 / 原片 / wav 原声约 880MB 且分散在站外文件夹，
若需线上提供原文件下载，请先把「熙叆」里的对应文件复制进站内，
并修改 js/site.js 中的路径配置（origDir / webDir / media / bgm）。

【其他】
- 与游戏联动：图库照片按时间排序，与《熙叆物语》中的 73 枚「时光碎片」一一对应；
  首页与页脚均有「进入游戏」入口。
- 主题音乐《魔法时间的童话》由原 wav 转换而来，游戏与本站共用。
