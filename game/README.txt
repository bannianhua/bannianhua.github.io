《魔法时间的童话 ～熙叆的时光物语～
==========================================

一部以「熙叆」文件夹里 73 张照片、3 段视频、1 段音频为素材制作的
视觉小说(Galgame)。照片按拍摄时间(2025 年夏 ~ 2026 年秋)排序,
编织成一年四季的童话。

界面风格与《熙叆角色资源站》完全统一 ——「黄昏魔法时间 · 向日葵」风:
奶油米白底、向日葵金、黄昏柔粉与叶绿,配飘落的向日葵花瓣与金色光尘。
两站互相链接:资源站顶栏「▶ 进入游戏」,游戏标题画面底部「熙叆角色资源站」。

【怎么玩】
1. 用 Chrome / Edge 浏览器双击打开 index.html 即可开始。
   (不要单独移动 index.html,它需要和 images / video / audio 文件夹在一起)
2. 鼠标点击(或 空格 / 回车)推进对话;再点一次可立即显示全文。
3. 键盘快捷键:
   L — 对话记录    A — 自动播放    Esc — 菜单
4. 底栏按钮:记录 / 自动 / 快进 / 存档 / 菜单。
5. 游戏会自动存档;也可以手动存 3 个槽位,标题画面可「继续旅程」。

【剧情】
深夜,你翻开一本旧书《魔法时间的童话》,被卷进时光王国,
遇见向日葵精灵熙叆——她是「黄昏下的天使」,把黄昏称作「魔法时间」,
能用双手比划就拍下风景。你们一起走过
夏·秋·冬·春四季,收集散落的记忆碎片;途中还会发现
三卷"会动的碎片"(特别影像)。羁绊值的多少,决定三种结局:
  ★ 永远的时间童话 (TRUE END)  — 羁绊 ≥ 125
  ★ 未完待续的四季 (GOOD END)  — 羁绊 70 ~ 124
  ★ 一个人的时光机 (BAD END)   — 羁绊 < 70

【内容】
  images/    73 枚时光碎片(mem_001~073,按时间排序,含 manifest.json 原文件对照表)
  video/     3 卷会动的碎片(ev_001~003,已转换为网页可播放的 mp4)
  audio/     主题音乐《魔法时间的童话》(由原 wav 转换,循环播放)
  js/        剧情数据 data.js 与游戏引擎 game.js
  css/       样式
  tests/     自动化测试脚本(通关测试 / UI 功能测试,可用 node 运行)

【其他】
- 进度与收集保存在浏览器 localStorage 中,清除浏览器数据会清空进度;
  也可以在「系统设置」里手动清除全部存档。
- 想改剧情:编辑 js/data.js(纯文本,结构清晰:PHOTOS 是照片表,
  SCENES 是场景台词表,choices 是选项与羁绊值)。
- 真结局通关后,片尾会播放全部时光碎片的蒙太奇。
- 相册里未解锁的碎片,写着它所属的章节;收集满 73 枚即可点亮整本相册。

愿魔法的时间,永远与你同在。
