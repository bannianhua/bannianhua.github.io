《黄昏塔 · 熙叆救出聆淅》
==========================================

一个像《杀戮尖塔》的卡牌策略肉鸽游戏原型，共 1200 层黄昏塔。
风格与“熙叆角色资源站 / 聆熙童话-web”统一：暖黄魔法时间、向日葵与黄昏光尘。

【怎么玩】
1. 用 Chrome / Edge 双击打开 index.html 即可开始。
2. 不要单独移动 index.html，它需要和 css/、js/ 文件夹放在一起。
3. 在 1200 层黄昏塔地图上选择路线：战斗 / 精英 / 事件 / 篝火，地图可横向滚动。
4. 战斗中每回合获得 3 点能量，抽 5 张牌；点击卡牌出牌，攻击卡会攻击敌人。
   多敌人时先点攻击卡，再点要攻击的敌人。
5. 胜利后可三选一获得新卡；篝火可回复生命或升级卡牌。卡组已拓展到 1107 张，包含阳光资源、消耗牌、能力牌、AOE、连击、弃牌回收等，构筑更有策略性。1200 层中会随机出现反伤、治疗、诅咒、时停、铁壁等机制怪，并且包含 1003 条随机事件。
6. 最终登上塔顶，击败“暴君·零”和“独裁者·灵”，救回聆淅。

【剧情】
因为梦的失误，聆淅直接进入到了梦中的银河铁道列车，遇到了灵和零。
别称“暴君”的零和别称“独裁者”的灵，因为想找个听话的仆人，便直接把聆淅催眠带走了。
之后熙叆和梦进入梦中后，妹妹聆淅已不见踪影，只留下了零和灵的纸条。
熙叆看到后，什么也没说，直接来到目的地“黄昏塔”来救出聆淅。
为此经历了艰难险阻，最终救回聆淅，和聆淅结婚。
